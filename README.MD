# Portfolio Website

## Project Description
A modern, responsive portfolio website showcasing me work as a Computer Science student, Game Developer, and Frontend Developer. The site features a clean, professional design with sections for about information, projects, and contact details. It includes interactive elements like theme switching, dynamic content loading, and comprehensive user feedback systems.

## Setup Instructions

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code recommended)
- Git installed on your machine

### How to Run Locally

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/portfolio-website.git
    cd portfolio-website
    ```

2. **Open the project:**
    - Navigate to the project folder
    - Open `index.html` in your web browser
    - Or use Live Server extension in VS Code for automatic reloading

3. **View the website:**
    - The portfolio will load in your default browser
    - No build process or dependencies required
    - All assets are included and ready to run
